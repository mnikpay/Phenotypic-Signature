# Phenotypic-Signature
This repository contains the r script (calculate_cor.r) and the database (psign_v1.1.dat) to identify functionally related genes for a candidate transcript. For example, the following command will identify genes that have similar function to ENSG00000211785. 

Rscript calculate_cor.r ENSG00000211785

The database is made of 4591 reference genes that are well annotated (Tbio genes from the Pharos website: https://pharos.nih.gov/).
